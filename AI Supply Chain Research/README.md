# AI Supply Chain Research

This folder is the supply-chain research database for the AI infrastructure value chain. It is maintained by the `supply-chain-researcher` Hermes profile.

## Operating principle

Use an **append-only material event archive** plus **curated active views**:

- Event notes are retained as evidence and updated with lifecycle status.
- The dashboard and active opportunity watchlist are aggressively curated.
- The supply-chain map is a living model updated when events change the current view.
- Deletion is reserved for duplicates, accidental test notes, or obvious noise.
